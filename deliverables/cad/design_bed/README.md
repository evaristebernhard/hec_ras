# 赣江西支桥下设计河床 CAD 交付说明

## 1. 成果定位

本目录中的“设计河床”是依据现有 CAD 中 15#/16#/17# 桥墩设计泥面高程、现状桥下断面，以及 WSE=22.190 m 时净行洪面积 5700 m²（总面积 5980 m²、等效阻水 280 m²）共同约束得到的水力筛选重建成果。

它们不是从原设计院图纸中恢复出的完整设计河床线，也不应被表述为原设计院正式整治线。若项目最终需要施工/审图意义上的正式设计河床，应由有权设计人员在本成果基础上确认或重新出图。

## 2. 推荐交付顺序

### A. 权威可编辑文件：DXF

`西支5断面_桥下设计河床_三方案叠加_R2013.dxf`

- 以原《西支5断面100-100，0906》DXF 为底图；
- 在原桥下断面的 CAD 世界坐标中叠加三种设计河床；
- 保留原图的断面、文字和其他实体；
- 是最推荐给外部人员查看、复核和继续编辑的文件。

另提供中心方案、局部型、分布型三份单方案叠加 DXF，便于分别出图。

### B. AutoCAD 兼容副本：DWG R2004

`dwg/` 目录中的 4 份 DWG 由上述完整叠加 DXF 经 GNU LibreDWG 转换生成。

选择 R2004 而非 R2000 的原因：本项目原图包含中文文字，R2004 往返转换能够保留本项目检查的中文标签；R2000 转换曾出现中文 iconv 编码错误，因此已不作为推荐交付格式。

DWG 已执行 DWG -> DXF 往返校验：

- 三个设计图层均保留；
- 中心/局部/分布方案分别保留 330 / 319 / 353 个顶点；
- 最大设计线坐标往返误差约 5.21e-11 m，可视为数值零；
- “西支桥下”“西支上游500米”等中文标签在往返 DXF 中仍可正常检索。

LibreDWG 在转换原图时仍报告 TABLESTYLE、HATCH、预览缩略图/部分对象句柄等警告，因此 DWG 应视为经过几何验证的兼容副本，而不是替代 DXF 的唯一权威文件。

### C. 独立设计断面 DXF

`赣江西支桥下_设计河床_*_R2000.dxf`

这些文件不依赖原五断面底图，模型单位直接为 m，适合只拿设计断面线给其他软件或设计人员二次使用。LibreCAD 已成功打开这些 DXF 并完成 PDF 输出测试。

不建议直接用 GNU LibreDWG 将这些“简化独立 DXF”转换成 DWG，因为早期测试发现简化 DXF 缺少完整 DWG BLOCK_CONTROL 元数据，转出的 DWG 往返会丢实体。需要 DWG 时请使用完整叠加版，或用 AutoCAD/ODA File Converter 对独立 DXF 重新保存。

## 4. 原图坐标回写关系

桥下断面从原 CAD 提取时得到：

- 横向比例：10 CAD unit = 1 m；
- 纵向比例：10 CAD unit = 1 m；
- station=0 对应 `cad_x = 391496.2307640212`；
- elevation=0 对应 `cad_y = 3193335.313820825`。

因此设计断面回写原图坐标为：

`cad_x = 391496.2307640212 + 10 * station_m`

`cad_y = 3193335.313820825 + 10 * elevation_m`

这保证了叠加设计线与原桥下断面在原图坐标中严格对齐。

## 5. 正式外发建议

若收件方使用现代 AutoCAD，优先发送：

1. `西支5断面_桥下设计河床_三方案叠加_R2013.dxf`；
2. 对应 `dwg/西支5断面_桥下设计河床_三方案叠加_R2004.dwg`；
3. `cad_delivery_validation.csv`；
4. 本 README；
5. 彩色设计河床预览图。

如果成果要进入正式商业设计流程，建议由 AutoCAD 或有合适授权的 ODA 工具打开权威 DXF，执行 AUDIT/修复后，再 SAVEAS 为收件方要求的 DWG 版本（通常可选较新的 DWG 2018 格式）。不要只把 LibreDWG 生成的 DWG 作为唯一存档。
