\begin{abstract}
本项目在不依赖 MIKE 商业许可的条件下，采用 HEC-RAS 7.0.1 一维稳定流作为主计算工具，以 Python 完成 CAD 数据恢复、几何构造、结果验收和敏感性整理。计算流量为 $Q=26{,}000\ \mthreeps$，基准 Manning 粗糙系数为 $n=0.030$，基准下游已知水位为 22.049342~m。

现状河床及 0.5、1.0、2.0 m 防冲刷工况分别采用 360、380、390、410 m$^2$ 等效阻水面积；设计河床工况采用 280 m$^2$ 阻水面积，并依据 CAD 中 15\#、16\#、17\# 桥墩设计泥面高程以及表列 5700~m$^2$ 行洪净面积构造受约束筛选断面。五个主工况和两套设计河床重建敏感性工况均完成正式 HEC-RAS 计算并通过 HDF 验收。

在桥上游约 100 m 的 RS=600 断面，0.5、1.0、2.0 m 防护相对现状的附加壅水分别约为 2.525~mm、3.803~mm、6.382~mm；设计河床筛选工况相对现状约高 0.183~m。下游控制水位在基准值上下各变化 0.50~m 后，三种防护的附加壅水仍保持毫米级，说明“防护设施对一维整体行洪水位影响较小”的相对判断稳定。设计河床三种合理重建方式之间的关键断面水位差仅约 0.10--0.18 mm，表明一维筛选结果对控制点之间的补线形式不敏感。

绝对洪水位则明显受下游边界影响，因此在缺少正式设计控制水位或水位--流量关系时，本报告不将某一绝对 WSE 作为最终设计定值。现有图纸亦未提供完整桥面、梁底/低弦及桥墩迎水尺寸，暂不具备建立严谨显式 Bridge/Culvert 模型的全部资料条件。
\end{abstract}

\section{HEC-RAS 模型建立}

\subsection{计算条件}
主模型采用 HEC-RAS 7.0.1 一维稳定亚临界流计算。主要参数如下：
\begin{itemize}[leftmargin=2.2em]
  \item 设计流量：$Q=26{,}000~\mathrm{m^3/s}$；
  \item Manning 粗糙系数：$n=0.030$；
  \item 收缩系数：0.10；扩散系数：0.30；
  \item 基准下游已知水位：22.049342~m；
  \item 五个主工况的等效阻水面积：280 / 360 / 380 / 390 / 410 m$^2$。
\end{itemize}

\subsection{等效阻水表达与 v2 修正}
等效阻水带的横向宽度不是任意指定，而是求解使 WSE=22.190~m 时“水面到河床之间的阻水面积”恰好等于目标阻水面积。

早期版本曾将 obstruction 顶高程也设为 22.190~m。当计算 WSE 略高于该值时，HEC-RAS 会允许水流从等效阻水体顶部通过，相当于桥墩阻水在洪水位附近被人工削弱。修正版 \modelversion{} 将两个概念分开：
\begin{itemize}[leftmargin=2.2em]
  \item 22.190~m 仅用于\textbf{校准阻水面积和横向宽度}；
  \item obstruction 顶高程采用 50~m 数值哨兵，使研究水位范围内不发生人工越顶。
\end{itemize}
该 50~m 仅为数值设置，不代表真实桥面或桥墩顶高程。修正后旧结论的量级不变，例如 2.0 m 防护在 RS=600 的相对壅水由约 6.41 mm 调整为约 6.38 mm，但高水位敏感性计算的物理表达更合理。

\subsection{模型运行与验收}
七个正式/敏感性 plan 的 HDF 结果均执行以下自动验收：
\begin{enumerate}[leftmargin=2.5em]
  \item HDF 根属性必须报告 \texttt{SI Units}；
  \item RS=500 必须报告 \texttt{Obstr Block Mode=1}；
  \item 计算信息必须出现 \texttt{Finished Steady Flow Simulation}；
  \item 计算信息不得包含 warning 或 error。
\end{enumerate}

HEC-RAS GUI 截图不作为当前版本的核心验收证据。现阶段以工程输入文件、计算 HDF、计算完成信息以及上述自动验收条件作为可复现依据；待后续获得稳定的软件窗口自动化流程后，再补充界面截图而不影响本报告数值结论。

RS=600 的三方案总范围仅约 0.177~mm，而中心方案相对现状效应约为 182.6~mm，二者相差约三个数量级。因此在\textbf{一维筛选层面}，控制点之间具体采用哪一种合理平滑补线并不会决定结论。

但这一结论不意味着当前重建线可替代正式设计图。若正式成果要求提交“设计河床线 DWG/DXF”，仍应使用原设计院/设计人员给出的整治线，或由设计人员依据疏浚、防冲刷及结构设计意图正式绘制。

\subsection{绝对水位不能据此定值}
在现状工况下，下游已知水位从 21.549342~m 提高到 22.549342~m 时，RS=600 的绝对 WSE 约从 21.901~m 变化到 22.863~m。因此虽然工况间相对差值较稳定，但绝对 WSE 对下游边界高度敏感。

在缺少正式设计控制水位、实测水位--流量关系或可靠正常水深参数时，报告中的 22.383251~m 等绝对水位应理解为\textbf{基准边界条件下的模型结果}，不能直接作为最终设计洪水位定值。

\section{显式桥梁模型资料审计}

为判断是否可以进一步升级为 HEC-RAS Bridge/Culvert 模型，程序对现有 DXF 中的桥梁结构文字信息进行了审计。目前可追溯信息主要包括：
\begin{itemize}[leftmargin=2.2em]
  \item 15\#/16\#/17\# 桥墩位置；
  \item 桩基、设计桩底、设计泥面、实测泥面、最大冲刷线；
  \item 防冲刷结构厚度与部分基础“顶面高程”信息；
  \item 图纸高程采用黄海高程系统等说明。
\end{itemize}

但目前未检索到能够完整确定桥梁水力开口的\textbf{桥面高程、梁底/低弦、桥下净空、完整墩身迎水宽度}等资料。因此现阶段不宜为了“模型更复杂”而人为猜测桥梁几何。

如果后续获得桥梁总体布置/立面图和结构尺寸，可在现有一维模型上继续建立显式 Bridge/Culvert，并比较其与当前等效阻水模型的差别。

\section{结论与建议}

\subsection{主要结论}
\begin{enumerate}[leftmargin=2.5em]
  \item \textbf{三种防冲刷设施的一维整体壅水很小。}在基准条件下，0.5、1.0、2.0 m 防护在桥上游 100 m 的附加壅水约为 2.5、3.8、6.4 mm；下游水位上下变化 0.5 m 后仍保持毫米级。
  \item \textbf{设计河床工况的主要影响来自断面缩小，而不是桥墩阻水面积。}尽管设计河床工况阻水面积 280 m$^2$ 小于现状 360 m$^2$，其规定净行洪面积仅 5700~m$^2$，使桥下平均流速提高到约 4.65~m/s，并在 RS=600 产生约 0.18~m 的水位抬高。
  \item \textbf{设计河床筛选重建对补线形式不敏感。}三种合理重建在关键断面的水位差仅约 0.10--0.18 mm，远小于其相对现状的分米级效应。
  \item \textbf{相对结论比绝对水位可靠。}绝对 WSE 对下游边界高度敏感，因此当前模型适合比较方案差值，而不是在缺少正式水文边界时给出最终设计洪水位定值。
  \item \textbf{模型计算链已经基本完成。}当前进一步提升成果质量的主要瓶颈已从数值计算转为工程资料：正式设计河床线、桥面/低弦和桥墩结构尺寸，以及正式下游控制边界。
\end{enumerate}

\subsection{后续建议}
\begin{enumerate}[leftmargin=2.5em]
  \item 获取桥梁总体布置图/立面图，重点核实梁底或低弦高程、桥面高程、墩身迎水尺寸；
  \item 获取正式设计洪水控制水位或水位--流量关系；
  \item 获取 Manning $n$ 的项目依据，并做最终粗糙率校准；
  \item 如成果要求提交正式设计河床 DWG/DXF，应以原始设计线或设计人员正式整治线为准；
  \item 只有在任务明确要求桥墩局部最大流速、冲刷或防护体局部流场时，再升级局部二维模型。
\end{enumerate}
