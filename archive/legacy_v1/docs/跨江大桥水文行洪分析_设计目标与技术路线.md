# 某跨江大桥水文与行洪分析——设计目标与技术路线

## 1. 项目定位

本项目目标是在 **不依赖 MIKE 商业许可** 的前提下，建立一个能够稳定复现、可重复计算的桥位河段一维水动力分析流程。当前主路线采用 **HEC-RAS 1D 稳定流 + Python 数据预处理/结果校核**。HEC-RAS 本身为免费软件但不是开源软件；Python 侧的数据处理、CAD 数据抽取与结果分析尽量采用开源库。

当前优先级不是做高复杂度二维局部流场，而是先形成可信、可比较的
一维结果。到 2026-08-30，**五个主工况均已完成正式 HEC-RAS 7.0.1 计算**。
其中设计河床工况采用“CAD 中 15# / 16# / 17# 设计泥面控制高程 + 表 2
5700 m² 行洪净面积”构造的受约束筛选断面；它不是从 CAD 中直接找到的
完整原始设计河床线。

## 2. 已知设计条件

### 2.1 设计流量

采用最大洪水工况：

- 计算流量 Q = **26,000 m³/s**。
- 采用 1D 稳定流计算；当前已按单一设计流量完成四个同几何工况对比。

### 2.2 五个目标工况与当前完成范围

依据已提供的《表2 某跨江大桥水文和行洪参数表》：

| 工况 | 桥墩阻水面积 (m²) | 附加阻水面积 (m²) | 河道行洪断面面积 S行洪 (m²) | 阻水比 d |
|---|---:|---:|---:|---:|
| 设计河床线 | 280 | 0 | 5700 | 4.9% |
| 现状河床线 | 360 | 0 | 6800 | 5.3% |
| 设置 0.5 m 高防冲刷设施 | 360 | 20 | 6780 | 5.6% |
| 设置 1.0 m 高防冲刷设施 | 360 | 30 | 6770 | 5.8% |
| 设置 2.0 m 高防冲刷设施 | 360 | 50 | 6750 | 6.1% |

阻水比按下式核验：

**d = (桥墩阻水面积 + 附加阻水面积) / S行洪 × 100%**。

现状河床线及三种防护工况共享同一套实测断面，只改变桥位等效阻水面积，
已分别建模计算。设计河床线的行洪断面面积为 5700 m²，不能通过只把
阻水面积从 360 m² 改成 280 m² 来替代。当前已依据 CAD 设计泥面控制点和
5700 m² 净面积约束构造独立筛选断面并完成计算；正式设计图仍需原始设计线
或由设计人员按整治意图绘制。

## 3. 现有 CAD 资料与几何数据目标

当前工作区包含 4 份 DWG：

1. `01-赣江西支特大桥抗冲刷防护（水下不分散混凝土）.dwg` —— AutoCAD 2004/2005/2006 格式；
2. `02赣江西支特大桥等值线图.dwg` —— AutoCAD 2007/2008/2009 格式；
3. `西支5断面100-100，0906.dwg` —— AutoCAD 2013-2017 格式；
4. `西支成果.dwg` —— AutoCAD 2004/2005/2006 格式。

CAD 数据处理目标是把 DWG 转为可程序化读取的 ASCII DXF，再由 Python（优先 `ezdxf`）抽取：

- 河道中心线及桥位；
- 断面桩号、断面线；
- 断面 station-elevation 点；
- 河床/岸线高程；
- 桥墩或防冲刷设施的平面位置、宽度和高程范围；
- 如图中存在纵断面或等高线，则用于估计河床纵坡和下游正常水深边界。

## 4. DWG → DXF 开源路线

### 4.1 首选：GNU LibreDWG

GNU LibreDWG 是 GPLv3+ 的自由软件。当前 0.13.4 手册说明，其 DWG 解码器可读取 r1.2 到 r2018，覆盖率约 99%，并自带 `dwg2dxf` 工具，可输出 ASCII/Binary DXF。现有 4 份 DWG 的版本均在其读取范围内，因此它是本项目严格开源条件下的首选转换器。

建议优先输出 **ASCII DXF R2013**；如后续 CAD/GIS 软件兼容性不好，再降级为 **R2000 ASCII DXF**。保留原 DWG，DXF 仅作为数据交换和 Python 读取中间件。

注意：LibreDWG 官方文档也提示 DXF 导出仍不是 100% 与 AutoCAD 兼容，复杂对象可能出现丢失或导入失败。因此转换后必须进行实体数、图层、坐标范围和关键几何抽查。

### 4.2 备选：libdxfrw / LibreCAD

`libdxfrw` 为 GPLv2+ C++ 库，包含 `dwg2dxf` 示例转换器；其 README 声称可读取 R14 至 V2015 的 DWG。对本项目较老的 2004/2007 文件可作为备选，但对标记为 2013-2017 的文件兼容性不如 LibreDWG 明确。

LibreCAD 本身开源，但其官方文档仍将 DWG 支持描述为 basic / initial support，因此不建议把 LibreCAD GUI 作为主转换链路。

### 4.3 不作为“开源方案”的工具

- QCAD Community Edition 是开源的，但 DWG 支持属于 QCAD Professional 的专有插件，因此不能作为严格开源的 DWG 转换方案。
- ODA File Converter 转换兼容性通常较好，但属于 freeware / proprietary，不是开源软件。若 LibreDWG 对某一文件失败，可作为人工兜底，而不是主流程。

## 5. HEC-RAS 建模层级

采用两级建模策略。当前已经完成 Level B；Level A 是否开展取决于正式成果深度要求。

### Level A：优先的显式桥梁模型

当 CAD 中能够恢复桥梁低弦、桥面、桥墩位置/宽度和上下游控制断面时，使用 HEC-RAS Bridge/Culvert 模块建立显式桥梁断面。

**当前状态：未完成。** 现有成果尚未把桥面、低弦和各桥墩作为显式
Bridge/Culvert 构件录入，因此当前结果不能用于桥墩局部流场或冲刷涡分析。

### Level B：最小可用的等效阻水模型

若桥梁详细几何不足，则以表 2 的阻水面积作为硬约束，在桥位断面设置等效 blocked obstruction / ineffective flow area，使五个工况的总阻水面积分别达到：

- 设计河床线：280 m²；
- 现状河床线：360 m²；
- 0.5 m 防护：380 m²；
- 1.0 m 防护：390 m²；
- 2.0 m 防护：410 m²。

该方案不追求桥墩附近二维流场，而是用于回答本项目当前最重要的问题：**在 Q=26,000 m³/s 下，不同阻水程度对一维水面线和行洪能力的相对影响有多大。**

**当前状态：五个主工况及两套设计河床重建敏感性均已完成。** HEC-RAS
`p01`–`p07` 均正常完成，结果 HDF 确认为 `SI Units`，桥下 RS=500 的
`Obstr Block Mode=1`。等效阻水 v2 将 22.190 m 仅作为阻水面积校准水位，
阻水体顶高程使用 50 m 数值哨兵，避免计算水位超过 22.190 m 时发生人工越顶。

## 6. 边界条件与当前缺口

### 6.1 上游流量

已确定：Q = 26,000 m³/s。

### 6.2 下游边界

当前五个主工况统一采用下游已知水位 **22.049342 m**。该值来自首轮现状
工况校准，并不等同于实测水位—流量关系，也不是 Normal Depth 边界。

已另外采用 21.549342 / 22.049342 / 22.549342 m 三个下游已知水位，对五个
主工况完成 15 个 HEC-RAS plan。0.5 / 1.0 / 2.0 m 防护在桥上游 100 m 的
相对现状壅水始终保持毫米级；因此“防护附加壅水较小”的相对判断较稳定。
但绝对 WSE 随下游边界显著变化，最终设计洪水位仍需正式水位—流量关系或
设计控制水位。

### 6.3 Manning 粗糙系数

如果资料没有给出 n 值，则根据河槽、滩地的材质/植被分别取初值，并进行敏感性分析。正式报告必须明确区分“资料给定值”和“建模假定值”。

## 7. 每个工况的核心输出

每个已计算工况统一输出：

1. 桥位上游、桥位、桥位下游关键断面的水面高程；
2. 相对基准工况的壅水高度 ΔZ；
3. 平均流速及桥位有效过流断面的代表流速；
4. 过水面积、湿周/水力半径、输水能力等断面水力参数；
5. 能量线高程与桥区能量损失；
6. Froude 数及流态判别；
7. 阻水面积、行洪面积、阻水比的回算核验；
8. 纵向水面线对比和工况汇总表。

1D 模型不能给出桥墩局部冲刷涡和二维速度分布，因此相关结论不得由 1D 结果过度外推。

## 9. 当前进度与下一步顺序

已完成：DWG→DXF、5 个实测断面提取、设计河床受约束重建、Python 标准步长、
STREAM-1D 校核、HEC-RAS 五主工况 + 两个设计河床敏感性工况、下游边界
15-plan 敏感性、HDF 自动验收与结果导出。

下一步按以下顺序推进：

1. 向设计资料获取或核实桥面、梁底/低弦、桥墩实际宽度与迎水方向尺寸；
2. 获取正式下游设计控制水位或水位—流量关系，用于绝对洪水位定值；
3. 获取 Manning n 的项目依据并进行最终粗糙率校准/敏感性；
4. 如成果要求提交正式“设计河床线”DWG/DXF，应由原设计线或设计人员整治意图完成绘图；
5. 资料补齐后再判断是否升级为显式 Bridge/Culvert；只有需要局部冲刷/流场时再做二维模型。
